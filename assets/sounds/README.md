# Assets - Sounds

This directory is reserved for audio assets.

In DIWALI BLAST 2026, all audio effects are procedurally synthesized in real-time using the **Web Audio API** in `js/sound.js`.

Synthesized Sound Effects:
1. **Rocket Launch Whoosh & Whistle**: Frequency-ramped oscillators with bandpass noise.
2. **Firework Explosion**: Low-frequency sub-bass boom with distortion and filtered explosive punch.
3. **Chrysanthemum Crackles ("Dragon Eggs")**: Rapid randomized highpass noise bursts.
4. **Cartoon Bomb Blast**: Intense burning fuse sizzle followed by sub-bass 35Hz shockwave thud.
5. **Anar (Flowerpot) Fountain**: Continuous rushing pressurized spray with rhythmic crackles.
6. **Sparkler (Phuljhadi)**: Sizzling high-frequency crackle and micro-bursts.
7. **Diya Chime**: Pure harmonic brass bell chime (Ghanti).
8. **Ambient Festive Drone**: Meditative Indian pentatonic drone (Sa-Pa-Dha) with gentle celestial crystal chimes.

Benefits:
- 100% self-contained: No missing 404 audio files or network latency.
- Dynamic stereo panning based on rocket launch X positions.
- Low memory footprint.
- Zero copyrighted audio assets.
