# Assets - Images

This directory is reserved for static image assets.

In DIWALI BLAST 2026, all graphics (festive Diyas, hanging Akash Kandil lanterns, Rangoli ornaments, Cartoon Bomb illustrations) are crafted as pure inline vector SVGs directly in `index.html` and Canvas vector draws in `js/fireworks.js`.

Benefits:
- Instant loading with zero HTTP requests.
- Infinitely scalable on high-DPI (Retina) screens.
- Hardware-accelerated CSS keyframe animations (flickering flame, swinging tassels, halo glow).
